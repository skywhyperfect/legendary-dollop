# AI-Завуч: Оркестратор для школы "Aqbobek" (AIS Hack 3.0)

**AI-Завуч (Оркестратор)** — это комплексная гибридная AI-система, созданная для автоматизации управленческих процессов в современных школах. Мы решили главную проблему: педагогический состав привык общаться в WhatsApp и противится новым приложениям, а руководство тонет в бюрократии и хаосе чатов.

Наша система не требует от учителей установки нового ПО! Они продолжают писать в WhatsApp, а наша платформа с помощью ИИ парсит, анализирует и маршрутизирует всю информацию прямо на Дашборд директора.

---

## 🚀 Архитектура и Гибридный подход

```text
       ┌───────────────┐        ┌───────────────────┐
       │               │        │                   │
    ┌──► Telegram Bot  ├────────► FastAPI Backend   │
    │  │ (Резерв/Голос)│  POST  │ (Central Parser)  │
    │  └───────────────┘        │                   │
    │                           │ + NLP & OpenAI    │
Учителя (Users)                 │ + RAG (FAISS)     │
    │                           │ + Smart Scheduler │
    │  ┌───────────────┐        │                   │
    └──► WhatsApp App  ├────────►                   │
       │ (Группа школы)│  POST  │                   │
       └─────┬─────────┘        └──────┬────────────┘
             │                         │ GET/POST
         Node.js                       ▼
       (Слушатель)              ┌───────────────────┐
                                │ Vite + React      │
                                │ Frontend Dashboard│
                                │ (Директор)        │
                                └───────────────────┘
```

**Гибридный контур**: Учитель скидывает в WhatsApp: *"Я заболела, не смогу провести 1 урок"*. Node.js микросервис перехватывает это, отправляет в центральный парсер (FastAPI). Там NLP понимает суть, делает RAG-проверку по приказам, находит окно у другого учителя на 1 урок и возвращает ответ прямо в WhatsApp: *"Найдена замена: Смирнова"* и выводит этот статус Директору в Дашборд.

## 🏆 Решенные критерии оценки (100%)

1. **Извлечение данных (30%)**: Хаотичные тексты и голосовые от учителей (Voice-to-Task) превращаются в жестко структурированный JSON с приоритетами и дедлайнами.
2. **Smart-замены (30%)**: Сервис `scheduler.py` парсит загруженные XLS файлы с расписанием и автоматически без "накладок" подбирает учителя по профилю (опираясь на приказ).
3. **Постановка задач (20%)**: Директор диктует голосом задачу, Whisper (через API) переводит в текст, LLM разделяет на подзадачи с исполнителями и RAG-оценкой.
4. **UX Дашборда (20%)**: React-панель в стиле WhatsApp Web. Большая, чистая, мобильно-адаптивная без лишних менюшек.

## 🛠 Установка и Запуск (Одной командой)

**Требования**: `Python 3.11+`, `Node.js 18+`, `npm`. Заполненный `.env` с `OPENAI_API_KEY`.

В корне проекта:
```bash
chmod +x run.sh
./run.sh
```

### Как запустить WhatsApp
После запуска `run.sh`, в консоли терминала появится **QR-код**. 
Откройте WhatsApp на телефоне -> Связанные устройства -> Привязка устройства -> Отсканируйте код.
С этого момента любой входящий текст в вашу WhatsApp учетную запись (или группу) ловится Оркестратором!
