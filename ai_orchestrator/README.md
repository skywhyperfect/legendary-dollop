# Покойо: Оркестратор для школы "Aqbobek" (AIS Hack 3.0)

**Покойо (Оркестратор)** — это комплексная гибридная AI-система, созданная для автоматизации управленческих процессов в современных школах. Мы решили главную проблему: педагогический состав привык общаться в WhatsApp и противится новым приложениям, а руководство тонет в бюрократии и хаосе чатов.

Наша система не требует от учителей установки нового ПО! Они продолжают писать в WhatsApp, а **Покойо** с помощью ИИ парсит, анализирует и маршрутизирует всю информацию прямо на Дашборд директора.

---

## 🚀 Архитектура и Гибридный подход

```text
       ┌───────────────┐        ┌───────────────────┐
       │               │        │                   │
    ┌──► Telegram Bot  ├────────► FastAPI Backend   │
    │  │ @legendarydolbot│  POST  │ (Central Parser)  │
    │  └───────────────┘        │                   │
    │                           │ + NLP & OpenAI    │
    │  Покойо Ассистент         │ + RAG (FAISS)     │
 Учителя (Users)                │ + Smart Scheduler │
    │                           │                   │
    │  ┌───────────────┐        │                   │
    └──► WhatsApp App  ├────────►                   │
       │ (Группа школы)│  POST  │                   │
       └─────┬─────────┘        └──────┬────────────┘
             │                         │ GET/POST
         Node.js                       ▼
       (Слушатель)              ┌───────────────────┐
                                │ Vite + React      │
                                │ Frontend Dashboard│
                                │ (Директор)        │
                                └───────────────────┘
```

**Гибридный контур**: Учитель скидывает в WhatsApp: *"Я заболела, не смогу провести 1 урок"*. Node.js микросервис (через WhatsApp-web.js) перехватывает это, отправляет в центральный парсер (FastAPI). Там Покойо понимает суть, делает RAG-проверку по приказам, находит окно у другого учителя на 1 урок и возвращает ответ прямо в WhatsApp: *"Найдена замена: Смирнова"* и выводит этот статус Директору в Дашборд.

## 🏆 Решенные критерии оценки (100%)

1. **Извлечение данных (30%)**: Хаотичные тексты и голосовые от учителей (Voice-to-Task) превращаются в структурированный JSON с приоритетами и дедлайнами.
2. **Smart-замены (30%)**: Сервис подбирает учителя по профилю, опираясь на реальное расписание и приказы МОН.
3. **Постановка задач (20%)**: Директор диктует задачу, Покойо декомпозирует её на подзадачи с исполнителями.
4. **UX Дашборда (20%)**: Премиальная панель управления в стиле WhatsApp/modern EdTech.

## 🛠 Установка и Запуск (Одной командой)

**Требования**: `Python 3.11+`, `Node.js 18+`, `npm`. Заполненный `.env` с `OPENAI_API_KEY`.

```bash
chmod +x run.sh
./run.sh
```
