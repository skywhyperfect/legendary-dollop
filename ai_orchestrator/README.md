## 🎯 Обзор проекта
**AI Orchestrator** (название *Покойо*) автоматизирует типовые школьные задачи:
- Учителя отправляют **сообщения в WhatsApp** (голосовые или текстовые) → автоматически создаются задачи.
- **Само‑назначение**: при ответе учителя ключевыми словами ("ок", "понял", "взял" и т.п.) система мгновенно присваивает задачу этому учителю.
- **Дашборд аналитики**: KPI в реальном времени, учёт инцидентов, статистика питания, отсутствие учителей и др.
- **AI‑генерируемые PDF‑отчёты**: выбираете период (неделя, месяц, квартал, произвольный) – AI формирует краткое резюме и готовый к печати документ.

Все компоненты построены на **FastAPI**, **React + TypeScript** и **SQLite**, что обеспечивает лёгкую, беззависимую установку.

## 🏗 Архитектура
```
legendary-dollop/
├─ ai_orchestrator/                # Python‑пакет (бекенд)
│   ├─ backend/
│   │   ├─ app/
│   │   │   ├─ api/               # роутеры FastAPI (bot_feed, tasks, analytics, …)
│   │   │   ├─ ai/                # LLM‑парсеры, RAG, голос‑в‑задачу
│   │   │   ├─ db/                # SQLite‑движок и миграции
│   │   │   └─ main.py            # точка входа FastAPI
│   └─ whatsapp/                  # Node‑мост, пересылает сообщения в /api/bot/whatsapp-webhook
├─ frontend/                       # React + Vite UI
│   └─ src/App.tsx                # дашборд + компонент GenerateReportButton
└─ orchestrator.db                 # SQLite‑БД (создаётся автоматически)
```
- **FastAPI** обслуживает JSON‑API и статические файлы.
- **WhatsApp‑мост** (Node.js) пересылает входящие сообщения в `POST /api/bot/whatsapp-webhook`.
- **Маршрут аналитики** (`/api/analytics/report`) собирает данные и возвращает готовый к печати HTML‑документ.
- **Фронтенд** периодически опрашивает бекенд, отображает карточки в стиле glass‑morphism и предоставляет селектор периода для отчётов.

## ✨ Функциональность
| Функция | Описание |
|---|---|
| **Интеграция WhatsApp** | Приём сообщений в реальном времени, автоматический парсинг и создание задач. |
| **Логика само‑назначения** | Ключевые слова подтверждения (`ок`, `принял`, `взял`…) автоматически назначают задачи от "Нераспознанный сотрудник". |
| **Расширение ключевых слов** | Поддержка естественного языка и многоязычных вариантов подтверждения. |
| **Дашборд аналитики** | KPI: количество сообщений, порций питания, отсутствие учителей, процент выполненных задач, список инцидентов и др. |
| **AI‑генерируемый отчёт** | Выбор периода (неделя, месяц, квартал, произвольный) → AI пишет краткое резюме → HTML‑документ готов к печати. |
| **Селектор периода в UI** | Вкладки + кастомный date‑picker в компоненте `GenerateReportButton`. |
| **Автоматическая миграция БД** | При отсутствии колонок (`chat_id`, `parsed_summary`, `location` и т.д.) они добавляются «на лету». |
| **Премиальный дизайн** | Glass‑morphism, яркие градиенты, микрo‑анимации, шрифт Google Inter. |

## 🚀 Быстрый старт (локальная разработка)
> **Требования**: Python 3.12+, Node 20+, npm, git.

```bash
# 1️⃣ Клонируем репозиторий
git clone https://github.com/skywhyperfect/legendary-dollop.git
cd legendary-dollop/ai_orchestrator

# 2️⃣ Создаём виртуальное окружение и устанавливаем зависимости бекенда
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3️⃣ Настраиваем переменные окружения (см. ниже)
cp .env.example .env
# отредактируйте .env при необходимости (OPENAI_API_KEY, WHATSAPP_TOKEN и т.д.)

# 4️⃣ Миграции БД (выполняются автоматически при первом запуске)
# вручную ничего делать не нужно – приложение создаст orchestrator.db

# 5️⃣ Запускаем FastAPI бекенд
uvicorn app.main:app --reload --port 8000

# 6️⃣ В отдельном терминале стартуем мост WhatsApp (Node.js)
cd ../../whatsapp
npm install   # один раз
node index.js   # пересылает сообщения на http://localhost:8000/api/bot/whatsapp-webhook

# 7️⃣ Запускаем React‑фронтенд (Vite)
cd ../../frontend
npm install
npm run dev   # откроет http://localhost:5173
```

Откройте дашборд, отправьте голосовое сообщение в WhatsApp и наблюдайте, как задача появляется мгновенно. Внизу вкладки «Аналитика» нажмите кнопку **AI‑Отчёт**, чтобы сформировать PDF.

## 📡 API бекенда
| Метод | Эндпоинт | Описание |
|---|---|---|
| `POST` | `/api/bot/whatsapp-webhook` | Приём сообщений из WhatsApp, их сохранение и запуск логики само‑назначения. |
| `GET`  | `/api/tasks/` | Список всех задач (с полями `is_accepted`, `is_completed`). |
| `GET`  | `/api/analytics/report` | Возвращает `{ html, stats }`. Принимает необязательные параметры `date_from` и `date_to` (YYYY‑MM‑DD). |
| `GET`  | `/api/bot/messages` | Сырые сообщения WhatsApp (для отладки). |
| `GET`  | `/ping` | Проверка работоспособности сервиса. |

Все даты хранятся в **локальном времени** (`datetime('now','localtime')`).

## 🎨 UI фронтенда
- **Дашборд** (`App.tsx`) – карточки в стиле glass‑morphism для задач, KPI и метрик директора.
- **GenerateReportButton** – новый компонент с вкладками периода (7 дней, месяц, квартал, произвольный) и полями выбора дат.
- **HTML‑документ готов к печати** – генерируется на бекенде; кнопка открывает его в новой вкладке и автоматически вызывает `window.print()`.

> UI построен на **ручных utility‑классах**, совместимых с Tailwind, без сторонних UI‑библиотек, что сохраняет небольшие размеры сборки и обеспечивает премиальный внешний вид.

## 🔐 Переменные окружения
Создайте файл `.env` в корне проекта:
```
# FastAPI
OPENAI_API_KEY=your-openai-key   # опционально – при отсутствии используется шаблонный ответ
# WhatsApp‑мост (пример)
WHATSAPP_TOKEN=your-whatsapp-token
# При желании можно задать путь к БД
SQLALCHEMY_DATABASE_URL=sqlite:///./orchestrator.db
```
Если `OPENAI_API_KEY` отсутствует или установлен в `mock`, система будет использовать детерминированный шаблонный резюме.
