# 🚀 Покойо (AI School Orchestrator)
### Интеллектуальное управление школой без смены привычек (AIS Hack 3.0)

**Покойо** — это экосистема для автоматизации операционных процессов в школах. Мы не заставляем учителей и завучей осваивать новые сложные интерфейсы. Вместо этого мы внедряем ИИ (Gemini + Whisper + RAG) в те инструменты, которыми они уже пользуются: **WhatsApp** и **Голосовые сообщения**.

---

## 💎 Уникальность проекта (USP)
- **WhatsApp Hybrid**: Учителя скидывают отчеты по питанию, инцидентам или болезням в привычный чат. Покойо мгновенно парсит их в JSON и выводит на дашборд.
- **Smart RUP Generator**: Первое решение, которое строит расписание с учетом реальных РУП (Рабочих Учебных Планов), профилей (ФизМат/ХимБио), деления на подгруппы (Казахский/Английский) и элективных связок (Физика или Химия).
- **Voice-to-Task**: Голос директора превращается в четкие задачи с дедлайнами и ответственными, которые улетают исполнителям через ботов.
- **RAG-регуляторика**: Встроенные знания приказов №110 (замены), №130 (питание) и №76 (аттестация). Система сама проверяет законность замен и действий.

## 🛠 Технологический Стек
- **Backend**: FastAPI (Python), SQLAlchemy, SQLite.
- **Frontend**: React (TypeScript), Tailwind CSS.
- **AI Core**: OpenAI/Gemini (LLM), Whisper (STT), FAISS (Vector Store for RAG).
- **Integrations**: WhatsApp Web JS Bridge, Telegram Bot API.
- **Export**: Pandas & OpenPyXL (Premium Ribbon Matrix Excel).

## 📊 Ключевые функции (Критерии 30/30/20/20)

### 1. Извлечение данных (30%)
Автоматический парсинг сообщений учителей. Понимает:
- Явки по питанию (1А - 25 детей).
- Медицинские случаи (Плохо в 302 кабинете).
- Инциденты (Сломался принтер).
- Отсутствие (Заболел, нужна замена).

### 2. Smart Substitution (30%)
Модуль для завуча, который решает проблему "Окна":
- Поиск замены по профилю (Математик заменяет Математика).
- Контроль коллизий (Учитель не может быть в двух местах).
- **Hardcore**: Поддержка элективов (Физика или Химия параллельно).

### 3. Task Management (20%)
- Голосовой ввод Whisper.
- Распознавание локаций (Каб 201, Библиотека, Спортзал).
- Само-назначение: при ответе "Ок" в чате, задача в БД переходит в статус "Accepted".

### 4. UX Дашборд (20%)
- Дизайн в стиле Glassmorphism.
- Ribbon-расписание: группировка по параллелям, печатный формат.
- Real-time лента событий из мессенджеров.
