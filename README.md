# AI-Завуч: Цифровой Окестратор Образования 🏛️🤖

> **Status**: Production-Ready MVP для хакатона **AIS Hack 3.0** (Трек: EdTech & AI Management)  
> **Партнер**: Образовательный комплекс «Aqbobek»  
> **Mission**: Уничтожить «узкое горлышко» в управлении школой. Превратить хаос WhatsApp-чатов, рутину замен и сложные приказы МОН РК в единую автоматизированную экосистему с концепцией **Zero Onboarding**.

---

## 🚀 Почему это "Grand Prix" решение? (100/100 по ТЗ)

Мы не заставляем учителей скачивать новые приложения. Мы внедряем AI в их естественную среду обитания — WhatsApp.

### 🏆 4 Столпа Архитектуры (Полное закрытие кейса)
1. **NLP-Парсер чатов (Извлечение данных - 30%)**: 
   - **Гибридная интеграция мессенджеров.** По ТЗ требовался Telegram-бот — мы реализовали его (`app/bot/bot_feed.py`), но пошли дальше и добавили **настоящую интеграцию WhatsApp** (`whatsapp-web.js`), чтобы учителя писали в привычной среде.
   - Агент читает неструктурированные сообщения напрямую из мессенджеров ("1А - 25 детей, 2 болеют") и автоматически формирует **Свод по столовой** на Дашборде директора.
2. **Smart Substitution Engine (Умные замены - 30%)**: 
   - При болезни учителя AI обращается к **реальной Excel-базе школы** (Нагрузка + Расписание). 
   - Находит свободного учителя *того же профиля*.
   - **Эксклюзив:** Перед утверждением замены алгоритм прогоняет решение через **RAG (векторную базу)** на соответствие Приказам МОН РК №110 и №130!
3. **Делегат / Voice-to-Task (Постановка задач - 20%)**: 
   - Директор надиктовывает: *"Сделайте хакатон, Назкен воду, Айгерим зал"*.
   - LLM (OpenAI Function Calling) декомпозирует голос в JSON, назначает исполнителей и дедлайны по базе сотрудников.
4. **UX Дашборда (20%)**: 
   - Премиальный Glassmorphism интерфейс.
   - Разделение: Мощный пульт для Директора и удобный мобильный Sync-экран для Учителей.
   - Генерация HTML-приказов по ГОСТу с возможностью печати в 1 клик.

## 🛠️ Архитектура (Как это работает?)

По ТЗ хакатона обязательно наличие Telegram-бота. **Наш официальный Telegram-бот:** [@legendarydolbot](https://t.me/legendarydolbot). Вы можете протестировать извлечение данных прямо в нем!

Но мы пошли дальше требований и реализовали гибридный контур:

```text
       ┌───────────────┐        ┌───────────────────┐
       │               │        │                   │
    ┌──► Telegram Bot  ├────────► FastAPI Backend   │
    │  │ @legendarydolbot│POST  │ (Central Parser)  │
    │  └───────────────┘        │                   │
    │                           │ + NLP & OpenAI    │
Учителя (Users)                 │ + RAG (FAISS)     │
    │                           │ + Smart Scheduler │
    │  ┌───────────────┐        │                   │
    └──► WhatsApp App  ├────────►                   │
       │ (Группа школы)│  POST  │                   │
       └─────┬─────────┘        └──────┬────────────┘
             │                         │ GET/POST
         Node.js                       ▼
       (Слушатель)              ┌───────────────────┐
                                │ Vite + React      │
                                │ Frontend Dashboard│
                                │ (Директор)        │
                                └───────────────────┘
```

**Workflow**: Учитель пишет в Telegram (@legendarydolbot) или рабочий WhatsApp: *"Я заболела, не смогу провести 1 урок"*. Система (Node.js/Telegram-webhook) перехватывает это и шлет в центральный парсер (FastAPI). NLP понимает суть, делает RAG-проверку по приказам МОН, находит "окно" у другого учителя по реальным таблицам Excel и выводит готовый приказ Директору на Дашборд!

## 🏗️ Развертывание локально

Система состоит из 3-х параллельных процессов.

### 1. Backend (FastAPI Core)
```bash
cd ai_orchestrator/backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 2. WhatsApp Bridge (Node.js Service)
```bash
cd ai_orchestrator/whatsapp
npm install
npm start
# Появится QR код в терминале для привязки "Телефона учителя"
```

### 3. Frontend (Dashboard)
```bash
cd ai_orchestrator/frontend
npm install
npm run dev
# Откроется на http://localhost:5173
```
