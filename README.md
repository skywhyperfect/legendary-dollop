# Покойо: Цифровой Окестратор Образования 🏛️🤖

> **Status**: Production-Ready MVP для хакатона **AIS Hack 3.0** (Трек: EdTech & AI Management)  
> **Партнер**: Образовательный комплекс «Aqbobek»  
> **Mission**: Уничтожить «узкое горлышко» в управлении школой. Превратить хаос WhatsApp-чатов, рутину замен и сложные приказы МОН РК в единую автоматизированную экосистему Покойо. Она работает там, где учителя уже привыкли общаться.

---

## 🚀 Почему Покойо - это "Grand Prix" решение? (100/100 по ТЗ)

Мы не заставляем учителей скачивать новые приложения. Мы внедряем **Покойо** в их естественную среду обитания — WhatsApp.

### 🏆 4 Столпа Архитектуры (Полное закрытие кейса)
1. **NLP-Парсер чатов (Извлечение данных - 30%)**: 
   - **Гибридная интеграция мессенджеров.** По ТЗ требовался Telegram-бот — мы реализовали его (`backend/bot.py`), но пошли дальше и добавили **настоящую интеграцию WhatsApp** (`whatsapp-web.js`), чтобы учителя писали в привычной среде.
   - Ассистент читает неструктурированные сообщения напрямую из мессенджеров ("1А - 25 детей, 2 болеют") и автоматически формирует **Свод по столовой** на Дашборде директора.
2. **Smart Substitution Engine (Умные заены - 30%)**: 
   - При болезни учителя Покойо обращается к **реальной Excel-базе школы** (Нагрузка + Расписание). 
   - Находит свободного учителя *того же профиля*.
   - **Эксклюзив:** Перед утверждением замены алгоритм прогоняет решение через **RAG (векторную базу)** на соответствие Приказам МОН РК №110 и №130!
3. **Делегат / Voice-to-Task (Постановка задач - 20%)**: 
   - Директор надиктовывает: *"Сделайте хакатон, Назкен воду, Айгерим зал"*.
   - LLM (OpenAI Function Calling) декомпозирует голос в JSON, назначает исполнителей и дедлайны по базе сотрудников.
4. **UX Дашборда (20%)**: 
   - Премиальный Glassmorphism интерфейс Покойо.
   - Разделение: Мощный пульт для Директора и удобный мобильный Sync-экран для Учителей.
   - Генерация HTML-приказов по ГОСТу с возможностью печати в 1 клик.

## 🛠️ Архитектура (Как это работает?)

По ТЗ хакатона обязательно наличие Telegram-бота. **Наш официальный бот Покойо:** [@legendarydolbot](https://t.me/legendarydolbot). 

```text
       ┌───────────────┐        ┌───────────────────┐
       │               │        │                   │
    ┌──► Telegram Bot  ├────────► FastAPI Backend   │
    │  │ @legendarydolbot│POST  │ (Central Parser)  │
    │  └───────────────┘        │                   │
    │                           │ + NLP & OpenAI    │
    │  Покойо Ассистент         │ + RAG (FAISS)     │
 Учителя (Users)                │ + Smart Scheduler │
    │                           │                   │
    │  ┌───────────────┐        │                   │
    └──► WhatsApp App  ├────────►                   │
       │ (Группа школы)│  POST  │                   │
       └─────┬─────────┘        └──────┬────────────┘
             │                         │ GET/POST
         Node.js                       ▼
       (Слушатель)              ┌───────────────────┐
                                │ Vite + React      │
                                │ Frontend Dashboard│
                                │ (Директор)        │
                                └───────────────────┘
```

**Workflow**: Учитель пишет в Telegram (@legendarydolbot) или рабочий WhatsApp: *"Я заболела, не смогу провести 1 урок"*. Система (Node.js/Telegram-webhook) перехватывает это и шлет в центральный парсер (FastAPI). NLP понимает суть, делает RAG-проверку по приказам МОН, находит "окно" у другого учителя по реальным таблицам Excel и выводит готовый приказ Директору на Дашборд!

## 🏗️ Быстрый старт (Одна команда)

Запустите скрипт в корне проекта для поднятия всех сервисов сразу:
```bash
./run.sh
```

### Структура проекта
- `backend/` — FastAPI сервер, логика парсинга, ИИ и базы данных.
- `frontend/` — React дашборд директора.
- `whatsapp/` — Node.js мост для интеграции с WhatsApp.
- `bot.py` — Telegram-бот (включается автоматически через run.sh).

## 🔑 Demo Bypass (Секретка для идеального Питча)
Сети на хакатонах часто падают. Мы предусмотрели **"Safety Switch"** для питча:
- Находясь на странице сканирования QR-кода (интерфейс учителя) — **нажмите прямо на большую иконку QR (в центре)**.
- Активируется 2.5-секундная красивая анимация "Синхронизации", после чего статус принудительно перейдет в Ready без реального интернета. Мэджик! ✨
